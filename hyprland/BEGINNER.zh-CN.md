# Hyprland 新手教程：从 GNOME 切换后的日常使用

这份教程按你当前的 Hyprland 0.57 配置编写，并核对了正在生效的快捷键。文中的 **Super 就是键盘上的 Win 键**。

Hyprland 的快捷键由配置决定。网上的“默认快捷键”可能和你这里不同，例如你这里的 `Super + Q` 是关闭窗口。

## 1. 先记住这六个操作

| 想做什么 | 当前操作 |
| --- | --- |
| 打开应用 | `Super + Space`，输入应用名称，按 Enter |
| 打开终端 | `Super + Enter` |
| 选中另一个窗口 | 鼠标移到窗口上，或 `Super + 方向键` |
| 关闭选中的窗口 | `Super + Q` |
| 进入／退出全屏 | `Super + F` |
| 切换到另一张桌面 | `Super + 数字` |

先用熟这六个操作，再学习后面的布局与配置。

## 2. 桌面的使用逻辑

### 窗口、焦点、工作区、显示器

**窗口**是某个程序的一扇窗口，比如浏览器窗口、终端窗口或网络连接窗口。一个程序可以有多扇窗口，一扇窗口也可以有多个标签页。

**焦点**表示“键盘输入和窗口快捷键现在会作用于谁”。当前配置启用了鼠标跟随焦点：把鼠标移到另一扇窗口上，焦点就会跟过去；点击窗口也可以选中它。活动窗口通常有更亮的蓝紫色边框。

**工作区**是一组窗口所在的虚拟桌面。例如工作区 1 放代码，工作区 2 放浏览器，工作区 3 放文档。切换工作区时，原来那组程序继续运行。

**显示器**是实际的物理屏幕。双屏可以同时显示两个不同的工作区；每块屏幕通常显示一个普通工作区。

你可以把关系理解为：**程序创建窗口，窗口放进工作区，显示器展示工作区，焦点决定当前操作哪个窗口。**

### 为什么新开的应用会自动分屏？

你现在用的是 `dwindle` 平铺布局。新窗口打开时，Hyprland 会自动分配空间，已有窗口也会重新排布。布局会受到当前焦点、可用空间和分割方向的影响，不必手动把每扇窗口拖到合适位置。

窗口开得越多，每扇窗口分到的空间就越小。日常使用时，建议把不同任务分到不同工作区，而不是把所有程序都塞进同一屏。

关闭一扇平铺窗口后，剩下的窗口会自动填补空间。

### 选中窗口和移动窗口是两件事

`Super + 方向键` 只改变焦点，不会移动窗口。例如编辑器在左、浏览器在右时，按 `Super + 右` 会把焦点交给右侧浏览器。

调整窗口位置可以按住 `Super`，再用鼠标左键拖动。平铺窗口会按布局重新放置；浮动窗口可以自由移动。

按 `Super + Q` 前先确认焦点。如果鼠标已经移到别的窗口上，关闭操作也会跟着作用于那个窗口。

## 3. 三种窗口状态怎么选

| 状态 | 效果 | 适合的场景 |
| --- | --- | --- |
| 平铺 | 自动安排窗口，共享屏幕空间 | 编辑器和终端、文档和浏览器并排 |
| 浮动 | 可以叠在其他窗口上，自由移动和缩放 | 网络连接、计算器、设置对话框 |
| 全屏 | 当前窗口占满所在屏幕，通常隐藏状态栏 | 专心写代码、看视频 |

### 浮动：Super + V

先选中窗口，按 `Super + V`，就能在平铺和浮动之间切换。

比如“高级网络设置”被平铺成一个特别大的窗口时，可以：

1. 把鼠标移到它上面。
2. 按 `Super + V` 切换为浮动。
3. 按住 `Super`，用鼠标左键拖动位置、右键拖动调整大小。
4. 用完后按 `Super + Q` 关闭。

### 全屏：Super + F

按一次进入全屏，再按一次退出。其他窗口仍然存在，退出全屏后就能看到当前工作区的平铺布局。

如果你觉得“其他窗口不见了”，先检查是不是有一扇窗口处于全屏状态。

### 最大化：Super + Shift + F

最大化会让当前窗口占用工作区域，保留状态栏所占的位置。再按一次恢复。

浏览器、Neovide、WezTerm 还可能有自己的 F11 全屏功能。新手先固定使用一种方式进入和退出全屏，避免同时切换应用和合成器的全屏状态。

## 4. 工作区：把任务分开，程序继续运行

### 切换工作区

`Super + 1` 到工作区 1，`Super + 2` 到工作区 2，以此类推；`Super + 0` 对应工作区 **10**。

例如先在工作区 1 打开编辑器，再按 `Super + 2` 打开浏览器。以后就可以用 `Super + 1` 和 `Super + 2` 在两组任务间切换。

### 把窗口搬到另一工作区

选中窗口后，按 `Super + Shift + 数字`。

例如把浏览器从工作区 1 搬到工作区 2：

1. 选中浏览器。
2. 按 `Super + Shift + 2`。
3. 按 `Super + 2` 查看它。

移动窗口后，当前配置通常不会自动跟随到目标工作区；窗口从当前屏幕消失不代表它被关闭。

### 双屏与工作区的关系

工作区编号属于整个 Hyprland 会话，并不是每块屏幕各自都有一套 1～10。

如果目标工作区已经位于另一块显示器上，切换到它会把焦点带到那块屏幕。新建工作区通常出现在当前聚焦的显示器上。当前配置没有把工作区编号固定绑定到某块显示器。

建议先把鼠标移到你想操作的显示器，再打开程序或选择一个尚未使用的工作区。不要把“工作区 2”理解成“第二块显示器”。

顶部状态栏显示工作区 1–10，数字后面的应用简称帮助记忆，例如 `1 Chrome`、`9 Neovide`。点击可以切换，鼠标悬停查看完整窗口列表；空工作区只显示数字。

`Super + O` 打开工作区缩略总览。点击卡片或按数字进入，方向键选择后按 Enter 确认，Esc 返回。
访问过的工作区会显示最近画面；还没有截图的工作区显示应用和窗口布局，并标明“预览未缓存”。

新增桌面面板、剪贴板、表情、音乐频谱和场景快捷键见 [桌面套件附录](DESKTOP-SUITE.zh-CN.md)。
按 `Super + Shift + T` 可选择配色与开启／关闭登录随机，见 [主题教程](THEMES.zh-CN.md)。底部 Dock 已自动隐藏，鼠标移到底边时显示。
按 `Super + Shift + C` 可更换鼠标外观、运动效果、摇动放大和尺寸，见 [鼠标教程](CURSORS.zh-CN.md)。

## 5. 完整快捷键速查

### 启动程序

| 快捷键 | 功能 |
| --- | --- |
| `Super + Space` | 统一搜索应用、文件与计算；再按关闭，Esc 退出 |
| `Super + Shift + Space` | 打开原 Wofi 应用菜单 |
| `Super + Enter` | 打开终端，优先 WezTerm，找不到则使用 Kitty |
| `Super + N` | 打开 Neovide |
| `Super + E` | 打开文件管理器 |
| `Super + B` | 用默认浏览器打开 Google |

`Super + Space` 打开的统一启动器会根据输入内容显示结果，不需要先选功能：

| 输入示例 | 结果与操作 |
| --- | --- |
| `Chrome` | 查找应用，方向键选择后 Enter 启动 |
| `README.md` | 搜索主目录中的普通文件，Enter 用默认程序打开 |
| `~/dotfiles/README.md` 或绝对路径 | 直接查找指定位置 |
| `12*34`、`(100+20)/3`、`2^10` | 实时计算，选中结果后 Enter 复制 |

普通搜索混合显示应用和文件，应用在前；算式的计算结果优先显示。文件搜索默认跳过隐藏目录、缓存与依赖目录。
选中文件后按 `Ctrl + Enter` 打开其所在文件夹。按 Esc 或再次按 `Super + Space` 关闭。

输入 `?` 查看所有功能。要使用以下快捷功能，在前缀后留一个空格：

| 输入示例 | Enter 的作用 |
| --- | --- |
| `w neovide` | 切换到匹配的已打开窗口 |
| `v 关键词` | 从剪贴板历史中复制选中项 |
| `g Neovim 教程` | 用浏览器搜索 Google |
| `github.com` | 在默认浏览器打开网址，无需前缀 |
| `dict exploitable` | 显示音标、释义与例句；选中后 Enter 复制 |
| `10 km to mile`、`32 f to c` | 换算单位并复制结果，无需前缀 |
| `p dotfiles` | 用 Neovide 打开项目 |
| `t workspace` | 在终端连接已有 tmux 会话，不存在则创建 |
| `s 日期` | 复制日期文字片段 |
| `锁屏`、`截图`、`切换主题` | 执行选中的桌面操作，无需前缀 |

例如，要快速找到另一扇 Neovide 窗口，按 `Super + Space`，输入 `w neovide`，用方向键选中后 Enter。
要继续之前的 tmux 工作，输入 `t workspace`，不用先手动执行 `tmux new -s workspace`。
词典需要联网，查询结果缓存 30 天；中文词典不可用时会尝试显示英文释义。单位换算区分 `GB` 与 `GiB`、位 `b` 与字节 `B`。

常用文字片段在 `~/.config/hypr/launcher-snippets.json` 编辑，条目使用 `name`、`description`、`keywords`、`content` 字段；`content` 中可用 `{{date}}`、`{{time}}`、`{{datetime}}`、`{{year}}` 自动替换当前日期时间。`s 邮箱` 默认复制本机 Git 邮箱，也可自行填写 `content`；没有设置邮箱时，会引导你编辑配置。
项目目录可在 `~/.config/hypr/launcher-projects.json` 配置，例如 `{"roots": ["~/dotfiles", "~/Projects"]}`。

需要原应用菜单时按 `Super + Shift + Space`，或运行：

```bash
wofi --show drun --conf ~/.config/hypr/wofi.conf --style ~/.config/hypr/wofi.css
```

### 哪些熟悉的操作目前没有绑定？

当前没有配置 GNOME 那样的单按 `Super` 窗口缩略图概览，也没有配置 `Alt + Tab`、`Alt + F4` 或通用的最小化快捷键。
`Super + Tab` 现用于切换应用，`Super + 反引号` 用于切换同一应用的窗口。

想暂时不看某个窗口，可以把它移到另一个工作区。Hyprland 的窗口管理快捷键与应用自己的快捷键互相独立：例如 `Super + Q` 关闭整扇终端窗口，WezTerm 的 `Ctrl + Shift + W` 则用于关闭当前标签页，并可能询问确认。

## 6. 状态栏和设置在哪里

文件快速预览、应用切换、截图识字和双屏布局记忆见 [四项桌面工作流](MACOS.zh-CN.md)。
文件管理器选中文件后按空格预览；统一启动器选中文件后按 `Alt + P`。

顶部状态栏是 Waybar，`Super + Space` 使用支持应用、文件搜索和计算的统一启动器；Wofi 保留为备用应用菜单，也用于主题、剪贴板等选择界面。它们都是配套程序，Hyprland 本身主要负责显示器、窗口、工作区和输入。

当前采用 Tokyo Night 蓝紫主题，顶部是三块悬浮面板。图标上停留鼠标可以查看提示；横屏、竖屏分别使用适配方向的光环壁纸。

| 状态栏入口 | 点击后的作用 |
| --- | --- |
| 左上角九宫格图标 | 打开控制中心；右键剪贴板；统一启动器使用 Super + Space |
| 工作区数字 | 切换工作区 |
| 网络／Wi-Fi | 打开网络连接编辑器 |
| 音量 | 打开控制中心；右键声音设置，中键静音，滚轮调音量 |
| 右侧托盘 | 查看 Fcitx5、网络和其他程序的托盘入口 |
| 中间时间 | 打开日历与系统面板 |
| 右侧铃铛 | 通知历史；右键勿扰 |
| 最右侧电源图标 | 电源菜单 |
| 底部 Dock | 聚焦常用应用、打开新窗口、选择运行中的应用 |

右上角的“有线”和无线网络名是两个独立入口，同时连接时都会显示。Wi-Fi 网络名上悬停鼠标可以查看信号与 IP。

GNOME 的设置程序仍然安装着，但其启动菜单入口默认只在 GNOME 显示。可以在终端打开：

```bash
XDG_CURRENT_DESKTOP=GNOME gnome-control-center
```

部分页面依赖 GNOME 会话，只能使用其中兼容的功能。Hyprland 的显示器排列、缩放、窗口规则和快捷键以 Hyprland 配置为准。

网络和声音也可以直接打开：

```bash
nm-connection-editor
pavucontrol
```

## 7. 你当前的两块显示器

| 显示器 | 摆放 | 分辨率／刷新率 | 缩放 | 逻辑位置 |
| --- | --- | --- | --- | --- |
| `DP-1` | 左侧横屏 | 3840 × 2160，75 Hz | 125% | `0x0` |
| `DP-2` | 右侧竖屏，顶部对齐 | 3840 × 2160，75 Hz，旋转 90° | 125% | `3072x0` |

旋转由 `transform = 1` 表示；反向竖屏是 `transform = 3`。竖屏的实际画面尺寸是 2160 × 3840，配置中的模式仍使用显示器提供的 3840 × 2160。

显示器位置使用缩放后的逻辑坐标。主屏逻辑宽度是 `3840 ÷ 1.25 = 3072`，所以右侧屏幕从 `3072x0` 开始。

右侧竖屏比左侧横屏向下延伸得更远。鼠标需要在两屏共同覆盖的高度内横向移动才能跨屏；在竖屏下半部分向左移动时，会碰到屏幕边缘。

当前配置中的显示器规则是：

```lua
hl.monitor({ output = "DP-1", mode = "3840x2160@75", position = "0x0", scale = 1.25 })
hl.monitor({ output = "DP-2", mode = "3840x2160@75", position = "3072x0", scale = 1.25, transform = 1 })
```

想用鼠标设置分辨率、旋转和排列，可选用 `wdisplays`，需要先安装：

```bash
sudo apt install wdisplays
wdisplays
```

图形工具的临时调整不等于已经写入 Hyprland 配置。要让重新登录或重新加载后也保留，应把最终设置保存到上述显示器规则中。

## 8. 用十分钟练一遍

1. 按 `Super + 1` 进入工作区 1，按 `Super + Enter` 打开终端。
2. 按 `Super + N` 打开 Neovide，观察两扇窗口怎样自动平铺。
3. 用 `Super + 左／右` 和鼠标移动分别切换焦点，观察活动边框。
4. 选中 Neovide，按 `Super + F` 全屏，再按一次恢复。
5. 按 `Super + 2` 进入工作区 2，通过 `Super + Space` 搜索浏览器并启动。
6. 按 `Super + 1`，确认刚才的终端和编辑器仍然存在。
7. 选中一扇测试窗口，按 `Super + Shift + 3` 搬到工作区 3，再按 `Super + 3` 查看。
8. 按 `Super + V` 切成浮动，尝试按住 Super 用鼠标移动和缩放。
9. 确认测试窗口没有需要保存的工作，再用 `Super + Q` 关闭。
10. 按 Print Screen 截取一小块区域，在支持图片的应用里粘贴。

双屏时，如果上述工作区已经在另一块屏幕上，操作可能会把焦点带到那里，这是正常行为。

熟悉后可以约定工作区 1 写代码、2 查资料、3 看文档、4 聊天。这只是方便记忆的用法建议，当前没有自动分配应用的规则。

## 9. 常见问题

### 应用没有右上角的 ×，怎么关？

先把鼠标移到该窗口上，再按 `Super + Q`。部分应用自己会绘制标题栏，部分应用没有；关闭窗口都可以使用这个快捷键。是否弹出保存确认由应用决定。

### 开了很多窗口，字和内容都挤在一起怎么办？

把不同任务搬到不同工作区；临时专注某一扇窗口时用 `Super + F` 或 `Super + Shift + F`。设置对话框可以用 `Super + V` 改为浮动。

### 移动窗口后，找不到它了？

先按目标工作区的 `Super + 数字`；再检查另一块屏幕，以及当前是不是有全屏窗口挡住了同一工作区里的其他窗口。

### 文字有锯齿或偏糊？

当前已关闭 XWayland 的最近邻像素放大：

```lua
xwayland = { use_nearest_neighbor = false }
```

这项设置在主配置的 `hl.config({ ... })` 内。它能平滑旧 X11 应用的放大，但 125% 仍然是分数缩放，部分旧应用可能偏软。浏览器等支持原生 Wayland 的应用与旧 XWayland 应用的表现可能不同。

本机旧版 WezTerm 的原生 Wayland 路径已遇到协议错误，因此当前保留它的 XWayland 配置。

### 锁屏、注销、重启有什么区别？

锁屏保留所有程序，解锁后继续工作；当前配置空闲五分钟会自动锁屏。

注销结束 Hyprland 会话，程序可能随之退出。`Super + Shift + E` 是立即注销，不是锁屏。重启则重启整个系统。注销或重启前先保存工作。

想回到 GNOME，保存工作并注销，在真正的登录界面选中用户后，从屏幕右下角的齿轮菜单选择 **Ubuntu** 再登录。锁屏界面没有桌面会话选择器。

## 10. 配置与排查命令

日常使用不需要改配置。以后需要调整时，主要文件是：

| 文件 | 用途 |
| --- | --- |
| `~/.config/hypr/hyprland.lua` | 显示器、快捷键、布局、圆角、动画、缩放 |
| `~/.config/hypr/waybar.json` | 状态栏模块、点击行为 |
| `~/.config/hypr/waybar.css` | 状态栏颜色、字体和样式 |
| `~/.config/hypr/bin/launcher` | 统一启动器入口 |
| `~/.config/hypr/lib/launcher_ui.py`、`launcher_search.py` | 启动器界面、应用与文件搜索、计算 |
| `~/.config/hypr/lib/launcher_features.py` | 查询前缀、帮助入口与桌面操作 |
| `~/.config/hypr/lib/launcher_context.py`、`launcher_knowledge.py` | 窗口、剪贴板、项目等快捷功能，词典与单位换算 |
| `~/.config/hypr/launcher-snippets.json` | 常用文字片段 |
| `~/.config/hypr/launcher-projects.json` | 可选的项目搜索目录 |
| `~/.config/hypr/wofi.css` | 备用应用菜单与选择界面样式 |
| `~/.config/hypr/swaync.json`、`swaync.css` | 控制中心与通知 |
| `~/.config/hypr/dock.json`、`dock.css` | 底部 Dock |
| `~/.config/hypr/wallpapers/` | 横屏、竖屏壁纸 |
| `~/.config/hypr/hypridle.conf` | 空闲锁屏时间 |
| `~/.config/hypr/hyprlock.conf` | 锁屏外观 |

`~/.config/hypr` 是指向 `~/dotfiles/hyprland/config` 的软链，修改任意一侧都会修改同一份文件。当前 Hyprland 使用 **Lua 配置格式**，网上旧版的 `bind = ...`、`monitor = ...` 不能直接复制进来。

修改前可以备份主配置：

```bash
cp ~/.config/hypr/hyprland.lua ~/.config/hypr/hyprland.lua.bak
```

检查配置语法和当前会话的错误：

```bash
Hyprland --verify-config --config ~/.config/hypr/hyprland.lua
hyprctl configerrors
```

Hyprland 通常会自动加载配置变化；需要手动重新加载时：

```bash
hyprctl reload
```

这会重新应用配置，包括显示器规则，不会主动注销会话。只修改了按键或外观时，可以用 `hyprctl reload config-only`，跳过显示器规则的重新加载。

查看当前显示器、窗口和已生效的按键：

```bash
hyprctl monitors
hyprctl clients
hyprctl binds
```

Hyprland 主配置热加载不会自动重启所有配套程序；例如修改 Waybar 的样式或模块后，需要另外重新加载或重启 Waybar。

当前主题提供了一条统一刷新命令，会检查主配置、重新加载通知，并重启状态栏和壁纸：

```bash
~/.config/hypr/bin/apply-theme
```

这条命令不会注销会话。菜单在下次打开时读取新样式，锁屏在下次锁定时读取新样式。
美化前的配置备份与恢复方法见 [主题与壁纸](README.md#主题与壁纸)。

### 新增动画怎么体验

- `Super + 数字`：随机使用横向推移、纵向电梯、缩略总览放大进入，避免连续重复。目标工作区若已显示在另一块屏幕，只会把焦点移到那块屏幕。
- `Super + O`：手动展开缩略总览，按数字或点击卡片进入；Esc 返回。
- `Super + 方向键` 或将鼠标移到其他窗口：焦点边框与窗口明暗柔和切换。
- `Super + 鼠标左键` 拖动浮动窗口、`Super + 鼠标右键` 调整尺寸：平滑移动与缩放。
- `Super + Space`：统一启动器淡入出现。
- 快速移动鼠标：指针轻微拉伸；快速来回摇动：临时放大以便找回指针。

这些效果沿用现有按键。关闭特效、插件升级及回退刷新率的方法见 [动画与鼠标](README.md#动画与鼠标)。
