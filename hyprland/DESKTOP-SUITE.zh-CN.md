# Hyprland 桌面套件使用附录

这套桌面沿用 Hyprland 的平铺、工作区和窗口操作，新增了统一配色的控制中心、日历面板、窗口搜索、剪贴板、表情选择和电源菜单。`Super` 就是键盘上的 Windows 键。

## 常用入口

| 快捷键 | 用途 |
| --- | --- |
| `Super + C` | 打开或收起控制中心 |
| `Super + D` | 打开或收起桌面面板 |
| `Super + W` | 搜索已经打开的窗口 |
| `Super + Shift + V` | 从剪贴板历史选择内容 |
| `Super + .` | 选择表情或常用符号 |
| `Super + Shift + P` | 打开电源菜单 |
| `Super + M` | 打开音乐频谱 |
| `Print` | 框选截图 |
| `Shift + Print` | 截取全部屏幕 |
| `Super + Print` | 标注最近一次截图 |
| `Super + Shift + T` | 选择桌面主题、设置登录随机 |
| `Super + Shift + C` | 更换鼠标外观、运动效果和尺寸 |
| `Super + Shift + B` | 切换下一张壁纸 |
| `Super + Space` | 搜索应用、文件、计算、查词及快捷操作 |
| `Super + O` | 查看工作区缩略图 |
| `Super + Tab` / `Super + 反引号` | 切应用 / 切同应用窗口；Shift 反向 |
| `Super + Shift + O` / `Super + Ctrl + O` | 框选识字 / 代码识字 |

多数菜单按 `Esc` 即可退出。桌面面板也可以点右上角的 `×` 收起。

文件管理器中选中文件按空格预览，启动器中用 `Alt + P`。桌面自动学习应用的屏幕与工作区布局。
详见 [文件预览、窗口切换、OCR 与布局记忆](MACOS.zh-CN.md)。

## 两个面板怎么用

**控制中心**用于通知和日常控制：查看通知历史、开启勿扰、调整音量和应用音量，以及进入网络、蓝牙、截图、锁屏和电源菜单。网络与蓝牙按钮打开相应设置程序；它们是入口按钮，不能把按钮颜色当作设备开关状态。

**桌面面板**用于查看时间、日历、CPU 使用率、内存、可读取的温度，以及当前媒体和网络连接。面板里的音量滑条直接调整系统音量，静音按钮切换静音。系统数据每两秒刷新一次，关闭面板后停止刷新。

状态栏中间的时间也可以打开桌面面板；右键时间打开控制中心。点击桌面面板中的“通知”会收起面板，再打开控制中心。面板里的网络、蓝牙、截图也会先收起面板，方便操作新窗口。

温度只显示当前机器能够读取的传感器；没有媒体播放时，播放控制不可用。天气已设为**北京**：顶栏左键天气可输入其他城市，右键打开当地天气网页。日历面板与顶栏共用数据，最多每半小时更新，断网时标记并显示上次缓存。

也可用命令设置或清除城市：

```bash
~/.config/hypr/bin/weather-settings Beijing
~/.config/hypr/bin/weather-settings --clear
```

## Dock 自动隐藏

Dock 平时隐藏，不占应用底部空间。把鼠标移到任一显示器最底边即可唤出，移开约 0.35 秒后收起。两块屏幕共用 Dock 进程，会同步显示和隐藏；全屏屏幕不会因触底唤出 Dock。可查看运行状态：

```bash
~/.config/hypr/bin/dock-autohide --status
```

## 更换主题

按 `Super + Shift + T`，从 Tokyo Night、Catppuccin、Nord、Gruvbox、Rosé Pine、Dracula、One Dark、Everforest 等 20 套配色中选择，可直接输入名称搜索。菜单也可切换“每次登录随机”开关；默认开启且避开上次，配置重载不重新抽取。详见 [20 套主题与登录随机](THEMES.zh-CN.md)。

鼠标外观与桌面配色分别保存。按 `Super + Shift + C` 选择 16 套指针、拉伸／倾斜／旋转效果、摇动放大及尺寸，详见 [鼠标操作教程](CURSORS.zh-CN.md)。

## 不记得窗口在哪个工作区

按 `Super + W`，输入应用名、窗口标题或工作区数字。每行显示“编号、工作区、应用、标题”，用方向键选择，按 `Enter` 直接跳到该窗口，按 `Esc` 取消。列表优先排列最近使用的窗口。

例如，输入 `Chrome` 找浏览器，输入文档名找 PDF，输入源文件名找编辑器。这个入口只搜索已经打开的窗口；要启动新应用，使用 `Super + Space`。

## 音量与亮度提示

键盘的音量增加、音量减少和静音键会显示底部提示，约 0.7 秒后消失。每次增减音量为 5%，上限为 100%。媒体播放、上一首和下一首仍由键盘媒体键控制。

亮度提示支持 `brightnessctl` 能读取的背光设备。普通外接显示器如果没有背光接口，会显示“显示器没有可用背光接口”；此时使用显示器自己的菜单调亮度。下面的命令只显示当前状态，不更改音量或亮度：

```bash
~/.config/hypr/bin/osd volume show
~/.config/hypr/bin/osd brightness show
```

## 剪贴板与表情

`Super + Shift + V` 显示剪贴板历史，输入文字筛选后按 `Enter`。选中的内容会重新放到剪贴板，再到目标应用按 `Ctrl + V`；终端通常使用 `Ctrl + Shift + V`。历史最多保留 100 项，只保存在本机。带敏感状态或密码管理器 MIME 提示的内容会跳过；未标记的普通复制内容仍会进入历史。

清空历史可执行：

```bash
~/.config/hypr/bin/clipboard clear
```

`Super + .` 打开内置表情和符号列表，可搜索中文名称，如“完成”“右箭头”“摄氏度”。选中后复制的是表情或符号本身，回到应用粘贴即可。

## 音乐频谱

播放音乐后按 `Super + M`，打开蓝、紫、粉渐变的频谱窗口。窗口读取当前默认音频输出，不会调整音量；没有声音时保持安静，连续五秒无输入后降低刷新。按 `Q` 或 `Super + Q` 关闭，频谱随窗口退出，不会在登录时自动运行。

音乐播放控制在桌面面板与顶栏媒体区域。桌面面板提供上一首、播放或暂停、下一首；顶栏媒体区域左键播放或暂停，右键下一首，中键上一首。频谱本身只显示声音变化。

## 截图、标注与壁纸

按 `Print` 框选区域，按 `Esc` 取消。`Shift + Print` 截取所有屏幕，`Super + Print` 打开最近截图的标注窗口。截图自动保存到图片目录下的 `Screenshots`，同时复制到剪贴板。截图通知中也有“标注”入口。

标注窗口使用 `A` 画箭头、`R` 画矩形、`T` 添加文字、`D` 模糊、`Ctrl + Z` 撤销；完成后保留原图，另存标注版本并复制。截图工具还提供更多入口：

```bash
~/.config/hypr/bin/screenshot menu
```

`Super + Shift + B` 依次切换 Orbit、Violet、Aurora、Dusk 四套壁纸，每套都有匹配横屏与竖屏的图片。支持 Swww 时使用简短过渡，无法启用时直接切换；当前选择会保存供下次登录恢复。

## 日间、夜间和专注

在任一面板选择场景即可切换：

- **日间**：关闭暖色滤镜，减弱非活动窗口变暗，关闭勿扰。
- **夜间**：使用 5200 K 暖色滤镜，适度降低非活动窗口亮度，关闭勿扰。
- **专注**：开启勿扰，加深非活动窗口变暗，停止边框色彩循环。

这些场景调整显示效果和通知行为，保留窗口切换动画。夜间滤镜需要当前显示输出支持相应色彩协议；它不等同于调低显示器背光亮度。

## 电源菜单

按 `Super + Shift + P` 打开菜单，选择锁屏、注销、睡眠、重启或关机。注销、重启和关机会先弹出确认框；先保存需要保留的工作。睡眠会先尝试锁定会话。

## 面板没有响应时

重启桌面面板和音量提示共用的后台服务：

```bash
~/.config/hypr/bin/desktop-panel --restart
```

该命令不会重启 Hyprland，也不会关闭应用。再次按 `Super + D` 即可打开面板。需要查看启动错误时，日志位于 `~/.local/state/dotfiles-hyprland/desktop-panel.log`。

窗口搜索失败时，可先运行以下只读命令确认窗口列表：

```bash
~/.config/hypr/bin/window-switcher --list
```

## 应用主题和终端

GTK3/4 和 Qt5/6 使用当前选中主题的配色，图标为 `Papirus-Dark`。新开的应用会读取主题；已经打开的应用可能需要自行重启。Flatpak 沙箱和自行绘制界面的应用可能使用自己的配色。缩放仍为 125%，不通过放大字体来掩盖显示问题。

终端沿用已有的 Tokyo Night 配色和透明背景，新开的 Bash 会显示蓝紫两行提示符。Neovim 保留原有的主题切换设置。使用应用菜单时，也可搜索“控制中心”“日历”“剪贴板”“音乐频谱”进入对应功能。

## 文件、依赖与备份

本轮新增程序和库放在 `~/.local/share/hypr-theme/`，GTK 主题放在 `~/.local/share/themes/Tokyonight-Dark/`，图标在 `~/.local/share/icons/`。本轮没有使用 sudo 安装依赖。基本的 `install.sh` 只安装基础桌面；迁移到新电脑时还要准备这些资源，详情见 `tools/desktop-resources.txt`。

修改前的完整 Hyprland 配置、Bash 和终端备份在：

```
~/.local/state/dotfiles-hyprland/before-desktop-suite-20261029-162120/
```

GTK/Qt 原配置与原 GSettings 值在其中的 `gtk-qt/`。GTK 图标、字体和颜色偏好也会影响返回 GNOME 后的用户外观。恢复时应先保留当前配置，再按备份恢复相应部分；`apply-theme` 会重新应用本套件外观。

重载整套外观：

```bash
~/.config/hypr/bin/apply-theme
```

顶栏、Dock、通知、面板和色温日志在 `~/.local/state/dotfiles-hyprland/`，对应 `waybar.log`、`dock.log`、`swaync.log`、`desktop-panel.log`、`night-light.log`。壁纸四套为 orbit／violet／aurora／dusk，每套都有横竖屏原生分辨率版本；按 `Super + Shift + B` 轮换，过渡随机使用扩散、擦拭或淡入。
